# Netflix Exploratory Data Analysis (EDA) using NumPy & Pandas

## Project Overview

This project performs a complete Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using **NumPy**, **Pandas**, and **Matplotlib**.

The objective is to clean raw data, analyze content trends, generate business insights, and build a recruiter-quality GitHub portfolio project.

---

## Dataset

* **Dataset:** Netflix Movies and TV Shows Dataset
* **Records:** 8,800+ titles
* **Features:** Movies, TV Shows, Country, Rating, Duration, Genres, Date Added, Release Year, and more.

## Key Business Insights

* Movies represent nearly 70% of Netflix's catalog.
* The United States contributes the largest volume of content.
* India is among Netflix's top regional content producers.
* TV-MA is the most common maturity rating.
* Netflix rapidly expanded its catalog during peak growth years.
* International content plays a significant role in Netflix's strategy.
